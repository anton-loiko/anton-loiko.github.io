# Quizly
> A modern quiz app built with React, Zustand, and Vite. It features animations using GSAP for a smooth user experience.

Feel free to visit app [Quizly](https://quizly-neon.vercel.app)


![Quizly](/images/quizly.jpg)

## Features

- 🧠 Multiple quiz categories with hundreds of questions
- 🎨 Smooth animations using GSAP
- 📱 Responsive and mobile-friendly
- ⚡ State management with Zustand
- 🔥 Fast bundling with Vite

## Technologies Used

- **React**
- **TypeScript**
- **Vite**
- **GSAP**
- **Zustand**

For more details, feel free to visit Quizly [GitHub](https://github.com/anton-loiko/quizly)
